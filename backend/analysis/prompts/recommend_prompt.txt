- 반드시 포함해야 하는 버킷: $must_buckets

[버킷 정책 요약]
$policy_summary
(각 버킷 비중은 min ≤ weight_pct ≤ max, 총합은 정확히 100.00%)

[버킷별 편입 가능 종목 코드]
$eligible_assets_by_bucket
(여기에 없는 코드는 사용 금지. 어떤 버킷은 비어 있을 수 있음)

[톤 가이드]
- 전문적·간결·행동지향. 상투적 문구 남발 금지. 고객 코멘트는 숫자 기반으로 구체화.
- 전문용어는 피하고 쉬운 표현으로, 문장은 짧게 작성합니다.

[검증 체크리스트(절대 출력하지 말 것)]
- allocations 총합=100.00, 각 버킷 min/max 준수
- must_buckets는 최소 min 이상 배정
- assets 합=버킷 weight_pct (assets 제공 시)
- 모든 숫자는 'allocations'와 $policy_summary에서만 인용(소수점 2자리)
- $horizon_desc는 그대로 사용(임의 변형 금지)
- 허용 목록 외 종목 코드 금지, 버킷명을 종목 코드로 사용 금지
- JSON 외 불필요한 텍스트 출력 금지
